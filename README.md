## Adicionar outras imagens

1. Organize em `campanhas/AAAA-MM/nome-da-campanha.jpeg`.
2. Use nomes sem espaços ou acentos e salve o arquivo no formato correspondente à extensão.
3. Faça o upload e confirme o commit.
4. Abra o arquivo e copie o link Raw.
5. Cole o endereço no campo de URL da imagem da Digisac e faça um envio de teste.

Para preservar campanhas já enviadas, use um nome novo para cada nova versão da imagem.

Este repositório é público. Inclua somente materiais de divulgação autorizados. Não inclua documentos de entregadores, dados pessoais, senhas, tokens ou configurações do sistema. O repositório do sistema permanece separado.
